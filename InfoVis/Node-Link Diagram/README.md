<h1>Node-Link Diagrams</h1>

The original dataset is first preprocessed using the file preprocessing.py. This gives a new set of edges in a csv file. These files are saved in the Edges directory. After this, different graph layouts are visualized using Gephi. The file graph_layouts.gephi contains each visualization. The images for the same are stored in the Images directory.

Prerequisites: Ensure you have Python 3.x, NumPy, Pandas, installed. You can install them using "pip install numpy pandas". 

Place the Script and Data: Put the script (preprocessing.py) in the Node-Link Diagram directory. 

Run the Script: Execute the script from the command line using python3 preprocessing.py.
