<h1>Contour Mapping</h1>

The file contour.py is used to create the contour visualizations for the given dataset. The GIFs are stored in the GIFs folder, named according to the variables used in the visualization. The python code stores an image for each contour plot. However, only certain images are retained and put in the report. Rest of the images are deleted.

Prerequisites: Ensure you have Python 3.x, NumPy, Pandas, Matplotlib, NetCDF4, and xarray installed. You can install them using "pip install numpy pandas matplotlib netCDF4 xarray". 

Place the Script and Data: Put the script (contour.py) in the Contour Mapping directory. 

Run the Script: Execute the script from the command line using python3 contour.py.
